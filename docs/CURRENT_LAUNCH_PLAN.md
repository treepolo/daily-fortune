# 目前上架計畫

> 狀態：暫定／可隨時調整
>
> 這份文件只記錄 2026-09-03 當下的工作順序，避免開發過程中偏離目前目標。它不是永久產品原則，也不限制未來產品方向；需求改變時可以直接修改或廢棄。

## 目前順序

1. ✅ 實機測試基礎抽籤功能。
   - 使用者已完成測試，目前未發現抽籤、重抽、當日保存等功能 bug。

2. ✅ v0.5 第一版廟宇視覺驗收。
   - 結論：方向正確，但 reveal 前張力不足，各吉凶視覺差距也太小。

3. ✅ v0.6 核心互動骨架完成。
   - 待抽畫面有籤筒與可抓取中央籤。
   - 使用者按住籤往上拉，超過門檻後才正式建立這次抽籤結果。
   - 「逆天改命!!」只回到待抽狀態，不直接產生新結果；再次抽出籤後才 reroll。
   - 籤抽出後進入 suspense，再由使用者拉開籤紙揭曉。
   - 抽籤提交、籤紙可揭、完整揭曉等節點有震動回饋。

4. ✅ 同版加入未來機率實驗能力，但 baseline 不啟用。
   - Remote Config 可依第幾次 reroll 指定不同完整 1～7 機率分布。
   - Remote Config 可另外啟用 pity／保底條件。
   - 預設仍為原本固定均勻分布，次數加成 OFF、保底 OFF。
   - 研究事件保留 reroll index、實際 distribution、probability policy、pity counter 與 guarantee triggered，避免後續分析把機制效果誤認成使用者行為。

5. 🚧 v0.6 實機驗收未通過，進行 v0.6.1 視覺／手感修正。
   - 籤紙下緣必須 1:1 跟隨手指，不可跑得比手指快。
   - 修正籤與籤筒圖層：仍在筒內的部分必須被筒身／前緣遮住。
   - 籤筒改為明確的六角柱造型。
   - 吉凶差異不能只靠改顏色；需要真正的動態／局部特效。
   - 特效集中在各項結果的「大凶／凶／小凶／平／小吉／吉／大吉」字樣本身，不把整行染色。
   - 籤紙改為接近實際籤紙的細長條比例，不再接近正方形卡片。
   - 優先維持閱讀性：中性高對比紙面、清楚標籤、局部特效不得吃掉文字。
   - 凶系與吉系使用明顯不同的視覺語言；大凶、大吉為額外極端狀態。
   - reveal 需保持連續性與節奏，避免多個硬切斷層；抽出的籤要自然銜接到 suspense，再銜接籤紙揭曉。
   - 文字改為標楷體取向；目前優先呼叫 Android 系統 DFKai-SB，裝置沒有該字型時由系統 fallback。
   - 背景廟宇需呈現遠景感；移除容易聯想到靈堂的頂部框線。

6. 實機驗收 v0.6.1。
   - 確認抽籤與籤紙手勢的跟手性。
   - 確認六角籤筒與遮擋關係正確。
   - 確認 suspense 流程連續、有節奏且夠期待。
   - 確認籤紙比例、閱讀性與標楷體實機效果。
   - 確認七級特效有清楚梯度，且凶／小凶與吉／小吉不會再混淆。
   - 大凶需特別晦暗壓抑；大吉需特別金光閃耀且有多彩亮點。
   - 確認效能、背景切換與重開 App 行為無回歸。

7. 部署研究後端。
   - Remote Config／A/B/n 多臂實驗。
   - 匿名事件接收與資料保存。
   - 設定 Android build 所需的遠端設定與事件上傳 endpoint。

8. 做一次完整整合驗證。
   - App 能取得遠端設定。
   - 不同 installation 能穩定取得對應 experiment variant。
   - 抽籤確實使用該 treatment。
   - 動態機率 baseline 關閉時與既有均勻模型一致。
   - 研究事件可以可靠上傳並保留 config／assignment／dynamic probability 脈絡。
   - 後端不可用時，App 仍可依 cached／embedded config 正常使用。

9. 決定是否在第一版上架前加入廣告能力。
   - 若加入，先把廣告 SDK／rewarded ad 流程與 Remote Config 開關放進 App。
   - 可先以遠端設定關閉廣告，上架後再開啟；不要求第一天就實際播廣告。
   - 目前既定產品構想仍是：一般「逆天改命!!」可要求完整廣告；若當前總體結果為大吉則免廣告直接重抽。

10. 最終整合測試後準備並上架 Google Play。

## 目前刻意不做

除非 v0.6.1 實機驗收或上架要求顯示有必要，現在先不擴張到：

- 大量額外動畫／特效 variant
- 完整 3D 廟宇場景或真實籤筒物理模擬
- 重型粒子系統
- 完整 server-driven UI
- 為所有 padding、字級、圓角等細節建立 Remote Config
- 使用者端統計 Dashboard
- 新的產品玩法

上述項目可以在上架後依實際需求與實驗計畫逐步新增，屆時再重新調整本文件。
