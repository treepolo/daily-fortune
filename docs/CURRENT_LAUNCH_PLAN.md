# 目前上架計畫

> 狀態：暫定／可隨時調整
>
> 這份文件只記錄 2026-09-03 當下的工作順序，避免開發過程中偏離目前目標。它不是永久產品原則，也不限制未來產品方向；需求改變時可以直接修改或廢棄。

## 目前順序

1. 實機測試目前 APK。
   - 今天第一次開啟 App 不自動抽籤。
   - 使用者按「抽籤」後才建立當日結果。
   - 正確顯示總體吉凶與財運、戀愛、工作／學業、人際、健康五項結果。
   - 「逆天改命!!」可以反覆重抽。
   - 關閉／重開 App 後，仍顯示當日最後一次抽取結果。
   - 跨日後重新等待使用者主動抽籤。

2. 若實機驗收發現功能問題，先修功能問題。

3. 若目前 UI 有明顯需要調整之處，將 baseline UI 修到可接受、可上架的程度。
   - 不要求現在一次做完所有未來動畫或視覺實驗。
   - 不為了避免未來更新而預先製作大量尚未確定會使用的 UI／動畫。
   - 已知可能做實驗的 UI 能力可保留 variant／parameter 介面；真正新的 UI／動畫能力日後仍可透過 App 更新加入。

4. 部署研究後端。
   - Remote Config／A/B/n 多臂實驗。
   - 匿名事件接收與資料保存。
   - 設定 Android build 所需的遠端設定與事件上傳 endpoint。

5. 做一次完整整合驗證。
   - App 能取得遠端設定。
   - 不同 installation 能穩定取得對應 experiment variant。
   - 抽籤確實使用該 treatment。
   - 研究事件可以可靠上傳並保留 config／assignment 脈絡。
   - 後端不可用時，App 仍可依 cached／embedded config 正常使用。

6. 準備並上架 Google Play。

## 目前刻意不做

除非實機測試或上架要求顯示有必要，現在先不擴張到：

- 大量新動畫／特效
- 完整 server-driven UI
- 為所有 padding、字級、圓角等細節建立 Remote Config
- 使用者端統計 Dashboard
- 新的產品玩法

這些都可以在上架後依實際需求與實驗計畫逐步新增，屆時再重新調整本文件。
