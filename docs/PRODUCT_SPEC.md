# 今日運勢：產品規格

## 1. 核心概念

每天的公共十二星座天命由「當日真實天象 + 固定占星規則」計算。使用者打開 App 是查看已經存在的今日天命；不接受時可按「逆天改命!!」，為自己的帳號建立私人古籤命運分支。

公共天命與私人改命是兩套刻意分離的來源：

- **公共天命**：沒有亂數。Astronomy Engine 計算實際星曆，Astrology Engine v1 依固定、可追溯規則算出十二星座的綜合與五細項運勢。
- **逆天改命**：使用安全亂數真正抽取公有領域古籤，抽過放回；結果只影響本人。

公共占星規則完整定義於 `docs/ASTROLOGY_ENGINE_V1.md`。

## 2. 每日公共十二星座天命

正式版以 `Asia/Taipei` 每日 00:00 為換日點。中央端針對當日完整 00:00–24:00 天象產生十二星座各一套天命，寫入後當日鎖定。

每套公共天命包含：

- 綜合運勢與分數。
- 財運。
- 戀愛。
- 工作／學業。
- 人際。
- 健康。
- 各項詳情敘述。
- Astrology Engine 版本。
- 可回溯的天文資料、成立規則與每項加減分 audit。

同一天、同星座、尚未改命的所有使用者看到完全相同的整包結果，包含細項與詳情。

正式公共天命禁止：日期＋星座亂數種子、使用者 ID 種子、臨時文案抽取或其他與天象無關的隨機因素。

## 3. 星座模型

固定順序：牡羊、金牛、雙子、巨蟹、獅子、處女、天秤、天蠍、射手、摩羯、水瓶、雙魚。

首次開啟選擇自己的太陽星座。因 App 不要求出生時間／地點，公共運勢只採太陽星座占星，不假裝知道完整本命盤。

星座是帳號設定：

- 當日已生效星座不能立即改掉逃離當天天命。
- 使用者要求修改時，自下一個 `Asia/Taipei` 曆日開始生效。
- 日後跨裝置同步。

## 4. 跑馬燈

首頁採老式電視新聞單行跑馬燈：

- 十二星座依固定順序循環。
- 每星座依序播「總運勢＋詳情、五細項＋各自詳情」。
- 詳情直接顯示，不藏在 `ⓘ`。
- 每次進首頁，第一次看到自己的星座前，至少完整經過 2 個星座、最多 11 個。
- 起點只影響顯示等待，不參與命運計算。

若本人今日已逆天改命，首頁跑馬燈只把本人的星座替換成私人命運；其他十一星座繼續顯示公共占星結果。

另保留「今日十二星座公共命盤」頁：永遠顯示原始公共世界線，即使本人已改命。

## 5. 吉凶等級

App 統一使用：大吉、吉、小吉、平、小凶、凶、大凶。

公共占星依分數門檻映射，門檻由 Astrology Engine 版本固定。細項獨立從自己的分數得到等級，因此整體很好仍可有凶細項，整體很差也可有吉細項。

## 6. 逆天改命

按「逆天改命!!」後：

- 只改本人／本人今日生效星座。
- 公共十二星座資料完全不變。
- 每次重新產生完整私人命運：綜合 + 五細項 + 古籤。
- 使用 `SecureRandom` 類型的安全亂數，不使用日期或帳號種子。
- 抽過放回，可能連續抽到同一支籤。
- 第一版沒有改命次數上限。
- 被改掉的歷史私人結果仍保留在統計事件中。

私人古籤優先使用公有領域《關聖帝君靈籤》100 籤；古籤原文不得臨時生成。現代說明由本專案自行撰寫。

### 未來廣告規則

第一版不接廣告。未來：

- 一般改命需完整觀看獎勵廣告後才抽。
- 如果目前私人／有效綜合運勢為大吉，按改命時免廣告，直接作廢大吉並重抽。

## 7. 統計

固定顯示：

- 總逆天改命次數。
- 平均每個使用日逆天改命次數。
- 最大單日逆天改命次數。
- 綜合大吉出現次數與比例。
- 綜合非凶比例。
- 綜合大凶出現次數與比例。

每日第一次查看自己的公共天命計入一次命運樣本；每次私人逆天改命也計入一次。被改掉的私人結果不刪除歷史統計。

`平均每日逆天改命 = 累計逆天改命次數 / 曾查看今日天命的日期數`

`大吉比例 = 歷史綜合大吉次數 / 歷史總命運樣本數`

`大凶比例 = 歷史綜合大凶次數 / 歷史總命運樣本數`

`非凶比例 = 歷史綜合（大吉 + 吉 + 小吉 + 平）次數 / 歷史總命運樣本數`

## 8. 帳號、雲端與離線

- 首次使用不設傳統註冊牆。
- 接 Supabase 後，自動建立匿名帳號。
- 日後可綁 Google 等正式登入，以跨裝置保存與復原。
- 公共天命由中央端產生、寫入並鎖定，Android 客戶端正式版只讀與快取。
- 個人改命由後端記錄並以帳號隔離。
- 已快取的今日公共天命離線仍可看。
- 如果裝置沒有今日快取且中央端不可用，顯示暫時無法取得；不得本機用種子補算一份正式天命。

## 9. 綁凶籤（後續）

凶級公共或私人結果可「綁起來」：

- 可附 0–20 字文字。
- 第一階段只讓本人看文字，可公開總綁籤數。
- 公開御神木／籤架與陌生人文字延後；開放時同步加入檢舉、封鎖、內容管理與服務條款流程。

## 10. 免費服務原則

第一版必要固定月費目標為 0 元：

- 天文計算：Astronomy Engine，MIT、無 API key、無每次費用。
- JPL Horizons：只作驗證，不是正式服務依賴。
- 後端：Supabase Free，在免費額度內運作。
- GitHub Actions：現有 Repo 的開發 CI。

不得在沒有產品需求的情況下引入必要固定月費服務。

## 11. 第一版暫不做

- 公開陌生人留言。
- 好友、追蹤、排行榜。
- 付費功能。
- 生成式 AI 即時占卜／解籤。
- 完整出生盤。
- 廣告。

## 12. 上架前必須完成

- 完整公共 Astrology Engine v1 與後端生成。
- 完整 100 籤私人改命資料。
- Room／SQLite 正式事件與快取層。
- Supabase 匿名帳號、同步、RLS。
- 星座隔日變更。
- 帳號刪除與隱私權政策。
- Release 簽章、AAB、商店資料與 Google Play 申報。
