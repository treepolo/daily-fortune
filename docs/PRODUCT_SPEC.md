# 今日運勢：產品規格

## 1. 核心概念

每天的公共十二星座天命由「當日真實天象 + 固定占星規則」計算。使用者打開 App 是查看已經存在的今日天命；不接受時可按「逆天改命!!」，把自己的世界線切到另一個物理可成立的平行天象，再用完全相同的占星規則重算。

兩種命運共享同一個 Astrology Engine：

- **公共天命**：沒有亂數。輸入是今天真實的完整天空。
- **私人改命**：亂數只負責選擇另一個可成立的完整星曆天空；行星位置本身不得各自亂數生成。選定後仍用同一套固定占星規則計分。

古籤、籤詩與任何古籤解說已淘汰，不得重新接回正式產品路徑。

完整占星規則定義於 `docs/ASTROLOGY_ENGINE_V1.md`。

## 2. 每日公共十二星座天命

正式版以 `Asia/Taipei` 每日 00:00 為換日點。中央端分析該曆日完整 00:00–24:00 天象，產生十二星座各一套天命，寫入後當日鎖定。

每套公共天命包含綜合運勢／分數、財運、戀愛、工作／學業、人際、健康、各項說明、引擎版本，以及可回溯的天文資料、成立規則與每項加減分 audit。

同一天、同星座、尚未改命的所有使用者看到完全相同的整包結果。正式公共天命禁止日期＋星座亂數種子、使用者 ID 種子、臨時文案抽取或其他與天象無關的噪音。

## 3. 星座模型

固定順序：牡羊、金牛、雙子、巨蟹、獅子、處女、天秤、天蠍、射手、摩羯、水瓶、雙魚。

首次開啟選擇自己的太陽星座。因 App 不要求出生時間／地點，公共運勢只採太陽星座占星，不假裝知道完整本命盤。

星座屬帳號設定：第一次選擇立即生效；後續要求變更時，從下一個 `Asia/Taipei` 曆日開始生效，避免用切換星座逃離當天天命。日後跨裝置同步。

## 4. 跑馬燈

首頁採老式電視新聞單行跑馬燈：十二星座固定順序循環；每星座依序播總運勢與五細項及其說明；詳情直接顯示；每次進首頁第一次看到自己的星座前至少完整經過 2 個星座、最多 11 個。

跑馬燈究竟顯示哪些因素、句子長度、標點與動畫速度屬展示層，可以在核心資料與後端完成後繼續調整，不影響 Astrology Engine 或資料 schema。

本人今日已改命時，首頁跑馬燈只把本人的星座替換成私人平行天象結果；其他十一星座維持公共世界線。另保留「今日十二星座公共命盤」頁，永遠顯示原始公共世界線。

## 5. 吉凶等級

統一使用：大吉、吉、小吉、平、小凶、凶、大凶。

五領域各自從自己的分數映射吉凶；綜合分數是五領域算術平均。因此整體很好仍可有凶細項，整體很差也可有吉細項。

## 6. 逆天改命

### 6.1 世界線規則

按「逆天改命!!」只改本人／本人當日生效星座，公共十二星座資料永遠不動。每次改命重新產生一個完整私人世界線，包含新的綜合、五細項、說明、天文 snapshot、占星 factors 與前後差異。

### 6.2 平行天象抽法

正式演算法：

1. 伺服器以安全亂數在允許年份範圍內抽一個不同年份；v1 為 1900–2100，原年份排除。
2. 以今天同月同日為中心，在目標年份 ±6 日內搜尋。
3. 計算各候選日 `Asia/Taipei` 正午太陽真黃道黃經。
4. 選擇與今日正午太陽黃經角距最小的候選日，維持近似相同的季節／太陽背景。
5. 直接採用該候選日完整 00:00–24:00 的星曆天空；月亮與所有行星都來自同一個真實星曆時刻序列。
6. 用與公共命運完全相同版本的 Astrology Engine 重算使用者星座。

禁止把水星、金星、火星等各自亂骰到不同角度，因為那會產生可能不存在於任何物理一致星曆中的天空。

同一個平行來源日可以再次被抽到；不做「抽過不放回」。

### 6.3 改命可能變差

系統不保證改命後變好，也不為了提高滿意度重抽或篩選候選天空。結果可以改善、惡化或近似不變。

若變差，產品可以直接說「很遺憾，你把命改得更差了」；這只是對分數差異的描述，不能改動實際結果。

### 6.4 前後差異

改命畫面必須能由 audit 真正導出：

- 原本綜合／五領域吉凶與分數。
- 改命後綜合／五領域吉凶與分數。
- 原世界線的重要因素中哪些消失。
- 新世界線新增哪些重要因素。
- 哪些因素造成主要分數變化。
- 平行天象來源日期與太陽黃經差。

說明文字不得先看結果再隨機配故事。

## 7. 統計

固定顯示總逆天改命次數、平均每個使用日改命次數、最大單日改命次數、綜合大吉出現次數／比例、綜合非凶比例、綜合大凶出現次數／比例。

每日第一次查看自己的公共天命計入一次命運樣本；每次私人改命也計入一次。被後續改掉的私人世界線仍保留在歷史統計。

`平均每日逆天改命 = 累計逆天改命次數 / 曾查看今日天命的日期數`

`大吉比例 = 歷史綜合大吉次數 / 歷史總命運樣本數`

`大凶比例 = 歷史綜合大凶次數 / 歷史總命運樣本數`

`非凶比例 = 歷史綜合（大吉 + 吉 + 小吉 + 平）次數 / 歷史總命運樣本數`

## 8. 帳號、雲端與離線

- 首次使用不設傳統註冊牆；接 Supabase 後自動建立匿名帳號。
- 日後可綁 Google 等正式登入，跨裝置保存與復原。
- 公共天命由中央端產生、交易寫入並鎖定；正式 Android 只讀與快取。
- 私人改命由後端安全亂數選平行天象並交易寫入；正式 Android 不自行宣告權威改命結果。
- 已快取的今日公共／私人結果離線仍可看。
- 無今日快取且中央端不可用時顯示暫時無法取得，不得自行生成一份冒充正式結果。

## 9. 綁凶運（後續）

凶級公共或私人結果可「綁起來」，可附 0–20 字文字。第一階段只讓本人看文字，可公開總綁定數。公開御神木／命運架與陌生人文字延後；開放時同步加入檢舉、封鎖、內容管理與服務條款。

## 10. 未來廣告規則

第一版不接廣告。未來一般「逆天改命」需完整觀看獎勵廣告；如果目前有效綜合運勢為大吉，按改命時免廣告，直接放棄該大吉世界線並重新改命。新世界線仍完全由正常平行天象抽法決定，不保證更好。

## 11. 免費服務原則

第一版必要固定月費目標為 0 元：

- 天文計算：Astronomy Engine，MIT、無 API key、無每次費用。
- JPL Horizons：只作驗證，不是 runtime 依賴。
- 後端：Supabase Free，在免費額度內運作。
- GitHub Actions：現有 Repo 的開發 CI。

不得無故引入必要固定月費服務。

## 12. 第一版暫不做

- 公開陌生人留言。
- 好友、追蹤、排行榜。
- 付費功能。
- 生成式 AI 即時占卜。
- 完整出生盤。
- 廣告。
