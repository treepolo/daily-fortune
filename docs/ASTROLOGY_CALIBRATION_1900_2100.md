# Astrology Engine v1 — 1900–2100 全量分布校準

本報告使用 `astrology-v1.0.0` 與 `astronomy-engine-2.1.19`，逐日計算 1900-01-01 至 2100-12-31 的完整日曆範圍。

- 實際掃描日數：73,414 天
- 每日星座數：12
- 實際計算命運數：880,968 筆
- 沒有抽樣：範圍內每一天、每一星座皆實際計算
- 百分位以 0.01 分直方圖估計；最小值、最大值與七級吉凶次數為精確統計
- 本輪只校準／診斷分布，**沒有修改任何吉凶門檻**

目前總運勢仍為五領域分數的算術平均，吉凶門檻仍為：

- 大吉：`>= 10.0`
- 吉：`>= 5.5`
- 小吉：`>= 1.8`
- 平：`(-1.8, 1.8)`（現行邊界依程式比較式）
- 小凶：至 `-5.5`
- 凶：至 `-10.0`
- 大凶：`<= -10.0`

## 校準結論

1. `±10` 並沒有造成大吉／大凶數學上不可達；歷史／未來完整範圍中有大量實例。
2. 總運勢的大吉約 3.76%、大凶約 4.30%，兩端合計約 8.06%。
3. 五領域的分布寬度與中心不同。工作／學業與健康整體偏負，人際整體偏正，若產品希望五領域有相近的吉凶基準，之後需要獨立討論是否做領域標準化；本輪未擅自修改。
4. 目前門檻可以產生完整七級結果，因此後續若要調整比例，應視為產品／模型校準決策，不能再以「極端等級實際不可達」為理由。
5. 新的逆天改命抽樣已取消同季節／同太陽黃經限制；1900-01-01 至 2100-12-31 的每個合法日期都可成為完整平行天象來源（原始當日本身排除）。

重現方式：執行 `.github/workflows/astrology-calibration.yml`。該 workflow 將 201 年拆成 12 個平行分片，最後合併精確級別計數、極值與 0.01 分直方圖百分位。
